# Lab 01 — Linux File Permissions & Ownership

## Objective
Understand how Linux controls access to files and directories through ownership and permission bits.

## Key Concepts
- File owner, group, and others
- Read (`r`), write (`w`), and execute (`x`) permissions
- Symbolic and numeric (octal) permission notation
- `chmod`, `chown`, and `chgrp`
- Directory traversal permissions and the principle of least privilege

## Practical Checklist
- [ ] Inspect file and directory permissions with `ls -l`.
- [ ] Create a test file and directory.
- [ ] Change permissions using symbolic notation.
- [ ] Change permissions using octal notation.
- [ ] Inspect ownership and, where permitted, change owner/group.
- [ ] Compare access as the owner, group member, and another user.
