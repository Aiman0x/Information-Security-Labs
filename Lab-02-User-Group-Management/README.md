# Lab 02 — Linux User, Group & Privilege Management

## Objective
Learn how Linux accounts and groups are managed and how administrative privileges are delegated safely.

## Key Concepts
- User and group accounts
- Primary and supplementary groups
- Account information files
- Administrative privileges and `sudo`
- Safe editing of sudo policy with `visudo`

## Practical Checklist
- [ ] Inspect the current account with `whoami` and `id`.
- [ ] View local user/group information.
- [ ] Create a test group and user in an authorized VM.
- [ ] Add a user to a supplementary group.
- [ ] Verify group membership.
- [ ] Review sudo policy without making unsafe changes.
