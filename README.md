# Information Security Labs

A practical documentation repository for Information Security coursework and hands-on cybersecurity labs at **University of Engineering and Technology (UET), Lahore**.

This repository organizes lab manuals, practical steps, command references, screenshots, observations, and learning notes. It is intended for educational use and authorized lab environments only.

## Repository Structure

Each lab folder follows a consistent layout:

- `README.md` — objective, concepts, procedure, results, and conclusion.
- `Commands.md` — commands used in the practical with short explanations.
- `Manual/` — original lab manual or PDF (to be added).
- `Screenshots/` — evidence screenshots (to be added).

## How to Use

1. Open a lab folder.
2. Read its overview and learning objectives.
3. Check `Commands.md` for the command reference.
4. Refer to the manual and screenshots when they are uploaded.
5. Add your observations and actual results after performing the lab.

## Documentation Standards

- Keep screenshots clear and label them in the order they were taken.
- Include the command and its output when documenting an important result.
- Do not upload passwords, API keys, private keys, tokens, or personal data.
- Redact public IP addresses and sensitive system details where appropriate.
- Clearly distinguish expected output from output observed on your own system.
- Use only systems and networks you own or are explicitly authorized to test.
